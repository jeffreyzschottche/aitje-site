# Ten models. One team. Control and independence.

Official page: https://aitje.com/en/cases/chatgpt-of-codex-in-je-eigen-organisatie

> AITJE set up a shared AI environment for a development agency, featuring Assistent, Coder and ten models to choose from. A shared token pool of €350 per month replaces nine subscriptions to €200. Model usage and token costs per task can be tracked via Asana.

Case study — Development agency / Assistant, Coder & model management

The developers used AI throughout the working day, but separate subscriptions made its use expensive and fragmented. Nine subscriptions from €200 amounted to €1,800 per month. Not every task requires the same model, whilst a technical fault or usage limit can interrupt work with a single provider.

AITJE Installed Assistent and Coder on an BOSGAME M5 with an additional server. A linked LLM management system brings together local models and external model APIs. Developers can choose from ten models and work within a single shared API budget. This brings project knowledge, code and model usage together into a single workflow.

## The approach

### Discuss

The Assistant helps the developer to think through the question and prepares the context for each project.

### Provide context

Skills, documentation and codebase conventions provide Coder with an understanding of the agency’s working methods.

### Deploying the model

Model management connects OpenCode to local models and external APIs via OpenRouter. The task determines which route is appropriate.

### Review costs

The integration with Asana shows which model was used and how many tokens the execution cost.
