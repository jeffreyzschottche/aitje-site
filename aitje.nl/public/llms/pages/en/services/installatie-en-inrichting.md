# Installation and setup: Your own AI environment. Delivered ready for use.

Official page: https://aitje.com/en/services/installatie-en-inrichting

> AITJE selects and configures hardware, a server or GPU-VPS for your AI solution. This can also be done on existing hardware or your own hosting. Software, models and storage are ready to use.

The right environment starts with what you want to do. An assistant for your team, a coding agent or a workflow with its own knowledge base each requires different capabilities and settings. AITJE will work with you to select a suitable computer or server and deliver the agreed AI solution, fully installed and set up.

You can use suitable hardware that you already have, choose a server or hosting provider yourself, or let AITJE find and set up the environment for you. The technical aspects, access, documentation and responsibilities are agreed in advance. This ensures that any missing files or limitations of existing hardware are identified in good time.

## Frequently asked questions

### What does ‘Installation and setup’ cover?

A basic installation starts at €199 excluding VAT: installing the agreed software, testing it and providing guidance in a familiar, suitable environment, with brief follow-up support as agreed. We estimate this will take two to two and a half hours. Product costs, hardware or server hire, networking, comprehensive knowledge base setup and integrations are quoted separately.

### Do I need to buy new hardware?

No. AITJE first assesses whether your existing hardware is suitable for the chosen models, the memory requirements and the expected usage. You can also purchase hardware yourself based on their advice. If a new environment is required, AITJE can help you find and arrange it.

### Can I choose my own server or hosting provider?

Yes. You can choose your own server or arrange the hosting yourself, after which AITJE will carry out the agreed installation. A check is carried out in advance to ensure that the capacity, operating system, access and network are compatible with the solution. It is also agreed who will be responsible for the hosting and ongoing management.

### What hardware and server environments does AITJE use?

AITJE It works with, amongst others, BOSGAME M5 and M6 and Mac mini, and for more demanding applications with, for example, NVIDIA DGX Spark or Dell PowerEdge. A droplet, VPS or GPU-VPS, for example at Nebius, may also be suitable. These are options, not fixed hardware requirements: the application, models and required capacity determine the choice.

### What do I need to provide before installation?

This will be agreed in advance. This includes information about previously purchased hardware, server access, network settings and the documents the solution needs to use, such as training materials or internal manuals. AITJE sets out what is required and when, so that any missing elements can be resolved as far as possible before implementation.

### Can AITJE differ from the standard installation?

Yes. For Assistent and Coder, AITJE has established procedures and installation guidelines. The choices made therein have been deliberately designed to ensure consistency between software, models, storage and management. If your situation requires a different setup, AITJE will assess the implications and agree the deviations and any additional work with you in advance.

### Can this be done remotely?

Often, yes. A server can usually be set up entirely remotely. An on-site visit is usually necessary if physical hardware needs to be connected.

### Can I use my AI environment securely from home or whilst on the move?

Yes. AITJE can set up remote access for you, with appropriate security and access rights. This feature is enabled separately and tailored to your network and the people who need to be able to use the environment.

### Can the same server run both AITJE Assistent and AITJE Coder?

AITJE Ideally, set up the Assistant and Coder in separate environments. This allows the capacity and configuration to be tailored to each product, and means they are less likely to interfere with one another when used simultaneously. A different architecture is possible if it suits your situation; the implications will be assessed in advance.

### How do I migrate my AI environment to different hardware?

A migration is preferably carried out in conjunction with ‘AITJE’, as a separate service. ‘AITJE’ helps you migrate the environment and export and transfer the vector database, text chunks and embeddings. Afterwards, checks are carried out to ensure that the knowledge base and the application are functioning correctly on the new hardware.
