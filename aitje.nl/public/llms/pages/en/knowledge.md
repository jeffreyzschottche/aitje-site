# Knowledge centre

Official page: https://aitje.com/en/knowledge

> Clear explanations of AI, models and your own AI environment. What is an LLM, what is local AI, what does an agent do? The AITJE knowledge centre.

AITJE is a Dutch AI specialist in local AI, automation and smarter workflows. Proprietary AI products, consultancy, development, installation and support, with independence as our guiding principle.

- [What is generative AI?](https://aitje.com/en/knowledge/wat-is-generatieve-ai): Generative AI creates new content based on a prompt: text, images, music, video, 3D or code. What happens during the generation process, and how do you turn an interesting result into something useful for your work?
- [What is text generation using AI?](https://aitje.com/en/knowledge/wat-is-tekstgeneratie): Text generation is the process of creating text using a language model. From draft emails and summaries to structured responses: the task and the available information determine the output.
- [What is image generation?](https://aitje.com/en/knowledge/wat-is-image-generation): Image generation, or ‘beeldgeneratie’, enables AI to create new images or modify existing ones. A description or reference provides guidance; the model constructs the visual output.
- [What is music generation?](https://aitje.com/en/knowledge/wat-is-music-generation): Music generation is the process of creating music using AI based on, for example, style, atmosphere, instruments or a sound clip. The model generates a musical composition which you can then listen to and edit.
- [What is speech and audio generation?](https://aitje.com/en/knowledge/wat-is-spraak-en-audiogeneratie): With AI, you can convert text to speech and generate other sounds. How do text-to-speech, sound effects and transcription differ, and where do they fit into a practical workflow?
- [What is AI-powered video generation?](https://aitje.com/en/knowledge/wat-is-videogeneratie): Video generation creates moving images from a description, an image or an existing clip. The model must not only produce attractive images, but also maintain continuity between successive frames.
- [What is 3D generation using AI?](https://aitje.com/en/knowledge/wat-is-3d-generatie): 3D generation creates a digital spatial representation based on text or images. From concept object to textured model: the output is only usable when it is compatible with your design software and application.
- [What is code generation using AI?](https://aitje.com/en/knowledge/wat-is-codegeneratie): Code generation allows a model to suggest, extend or adapt software code. The real value lies in the proposal fitting the existing project and being able to be implemented in a controlled manner.
- [How does generation work with diffusion models?](https://aitje.com/en/knowledge/hoe-werkt-generatie-met-diffusion-modellen): Many generative image models construct an image through successive steps starting from noise. What roles do the model, the prompt and the settings play during that process?
- [AI generation locally or via an API?](https://aitje.com/en/knowledge/ai-generatie-lokaal-of-via-een-api): Text, images and other output can sometimes be generated on your own hardware or produced via an external model service. Which approach best suits your data, desired quality and intended use?
- [What are frontier models?](https://aitje.com/en/knowledge/wat-zijn-frontier-modellen): Frontier models are at the cutting edge of what AI is currently capable of. What does that say about quality, and when do you really need such a model?
- [What are open-source AI models?](https://aitje.com/en/knowledge/wat-zijn-open-source-ai-modellen): Open source, open weights and free access do not mean the same thing. Find out what you can download, customise and run yourself — and what rights you need to do so.
- [What are tokens in AI?](https://aitje.com/en/knowledge/wat-zijn-tokens): A language model works with tokens: small building blocks of input and output. They help determine how much context fits, how long a response takes and what an API request costs.
- [What is model routing?](https://aitje.com/en/knowledge/wat-is-modelrouting): With model routing, a workflow selects which AI model will carry out a task. This allows you to combine local models and external APIs based on quality, data and costs.
- [What is quantisation in AI models?](https://aitje.com/en/knowledge/wat-is-quantisatie): Quantisation stores model data with lower precision. As a result, a model may require less memory, but the impact on speed and quality varies depending on the application.
- [What is fine-tuning?](https://aitje.com/en/knowledge/wat-is-fine-tuning): Fine-tuning further trains an existing model using targeted examples. When is this helpful, and when are a better prompt or document search function sufficient?
- [What is tool calling?](https://aitje.com/en/knowledge/wat-is-tool-calling): With tool calling, a language model can suggest calling a function. Your software retrieves data or performs an action, within the permissions you set yourself.
- [What is MCP, the Model Context Protocol?](https://aitje.com/en/knowledge/wat-is-mcp): MCP provides AI applications with a unified way of accessing tools and information sources. What does this make easier, and what do you still need to sort out yourself?
- [What are AI hallucinations?](https://aitje.com/en/knowledge/wat-zijn-ai-hallucinaties): AI can provide a convincing answer that is factually incorrect. Learn how to recognise fabricated information and build applications that handle uncertainty more effectively.
- [What is digital sovereignty?](https://aitje.com/en/knowledge/wat-is-digitale-soevereiniteit): Digital sovereignty is about having control over your data, systems and choices. In the context of AI, this also encompasses model access, management and the ability to switch providers.
- [What is ablation in language models?](https://aitje.com/en/knowledge/wat-is-abliteration): Abliteration adjusts a model’s internal properties to reduce learned rejection behaviour. What does this change, and what does it not tell us about the quality?
- [What are the weights of an AI model?](https://aitje.com/en/knowledge/wat-zijn-model-weights): Weights are the trained numbers that determine how a model processes information. Find out how model weights, parameters and a downloadable model file are related.
- [What is KV-cache in an LLM?](https://aitje.com/en/knowledge/wat-is-kv-cache): The KV cache stores intermediate results from a language model, so that it does not have to repeat as much work during text generation. This helps with speed, but also requires memory.
- [What is a vector in AI?](https://aitje.com/en/knowledge/wat-is-een-vector): A vector is an ordered sequence of numbers. In AI, such a sequence helps to represent, compare and retrieve information — for example, when searching by meaning.
- [What is a token factory?](https://aitje.com/en/knowledge/wat-is-een-token-factory): A ‘token factory’ is a metaphor for infrastructure that produces AI output. What lies behind such a factory, and how does this relate to inference and costs?
- [What is inference in an LLM?](https://aitje.com/en/knowledge/wat-is-inference): Inference is the process of using a trained model to produce an outcome. In the case of an LLM, this involves processing input and then constructing a response.
- [What is a vision model?](https://aitje.com/en/knowledge/wat-is-een-vision-model): A vision model processes visual information, such as photographs and document images. A vision-language model combines this with language to answer questions about an image.
- [What is a coding model?](https://aitje.com/en/knowledge/wat-is-een-coding-model): A coding model is designed for tasks involving software code. It can assist with explanations, additions and modifications, but a functioning development environment also requires tools and tests.
- [What is a VC subsidy for AI services?](https://aitje.com/en/knowledge/wat-is-vc-subsidy): Investors and temporary grants can finance growth before a service pays for itself. How might such a potential grant affect your view of AI costs?
- [What is loss-leader pricing in the context of AI?](https://aitje.com/en/knowledge/wat-is-loss-leader-pricing): With loss-leader pricing, an offer is priced at a loss to attract customers. How does this differ from a temporary discount, finance options and predatory pricing?
- [What is predatory pricing, or price gouging?](https://aitje.com/en/knowledge/wat-is-predatory-pricing): Predatory pricing refers to low prices that can exclude competition. Why is a cheap AI API not in itself evidence of such a practice?
- [What is vendor lock-in in AI?](https://aitje.com/en/knowledge/wat-is-vendor-lock-in): Vendor lock-in occurs when switching suppliers becomes difficult or expensive. With AI, this dependency often lies in data, APIs, model behaviour and workflows all at once.
- [What is an LLM?](https://aitje.com/en/knowledge/wat-is-een-llm): An LLM is a large language model that can understand, predict and generate text. It often seems intelligent, but the quality of the result depends heavily on context, model choice and how you use it.
- [What is edge AI?](https://aitje.com/en/knowledge/wat-is-edge-ai): Edge AI means that AI runs close to the source of the data, for example on a device, server or local network. This allows you to work faster and often gives you greater control over privacy, continuity and costs.
- [What is local AI?](https://aitje.com/en/knowledge/wat-is-local-ai): Local AI means that AI runs within your own environment, for example on a local device, server or network. It is about having greater control over data, availability, costs and dependence on external AI platforms.
- [What is on-premises AI?](https://aitje.com/en/knowledge/wat-is-on-premise-ai): On-premise AI means that AI runs on infrastructure managed by your own organisation or at your own premises. This can help with privacy, compliance, business continuity and control over systems.
- [White-label hardware, AITJE software](https://aitje.com/en/knowledge/white-label-hardware-aitje-software): White-label hardware with ‘AITJE’ software means that ‘AITJE’ selects suitable hardware and provides the software layer, configuration and AI functionality tailored to the application.
- [What is RAG?](https://aitje.com/en/knowledge/wat-is-rag): RAG is a method whereby a language model first retrieves relevant information from documents or a knowledge base before providing an answer. As a result, answers are often more specific, better substantiated and more useful for your own organisation.
- [What is context in AI?](https://aitje.com/en/knowledge/wat-is-context): Context is all the additional information you provide to a model so that it better understands what you mean. Good context makes the difference between a generic answer and something that really suits your task, organisation or document.
- [What is a context window?](https://aitje.com/en/knowledge/wat-is-een-context-window): The context window is the maximum amount of information a model can process in a single interaction. This determines how much text, chat history or document fragments can be used at any one time.
- [What is an AI agent?](https://aitje.com/en/knowledge/wat-is-een-ai-agent): An AI agent is a system that not only provides answers, but can also take steps towards a goal. This includes retrieving information, making choices, using tools and carrying out a task partly automatically.
- [What are embeddings?](https://aitje.com/en/knowledge/wat-zijn-embeddings): Embeddings convert text into vectors so that systems can recognise pieces of information that are similar in content. They form an important foundation for semantic search and many RAG applications.
- [What is prompt engineering?](https://aitje.com/en/knowledge/wat-is-prompt-engineering): Prompt engineering is the deliberate formulation of instructions to ensure a model produces useful output. It is not about tricks, but about clarity regarding the objective, context, tone, preconditions and desired format.
- [What is an API?](https://aitje.com/en/knowledge/wat-is-een-api): An API is an agreed method by which systems exchange data or functions with one another. It is the interface that allows software to communicate with other software without the need for manual copying and pasting.
- [What is a webhook?](https://aitje.com/en/knowledge/wat-is-een-webhook): A webhook is an automatic message sent from one system to another as soon as something happens. This allows you to trigger processes immediately without having to constantly check for new information.
- [What is a backend?](https://aitje.com/en/knowledge/wat-is-een-backend): The backend is the part of the software where processing, logic, integrations and data flows run behind the scenes, out of the user’s view. It is the technical layer that ensures an app or website can actually do something.
- [What is a front-end?](https://aitje.com/en/knowledge/wat-is-een-frontend): The front end is the part of the software that users see and interact with directly. It encompasses screens, forms, feedback and interaction, and therefore relates to how user-friendly and intuitive a system is in practice.
- [What is the cloud?](https://aitje.com/en/knowledge/wat-is-cloud): By ‘cloud’, organisations usually mean software, storage or computing power made available via external infrastructure. This offers flexibility, but also involves decisions regarding data, dependency and management.
- [What is a workflow?](https://aitje.com/en/knowledge/wat-is-een-workflow): A workflow is the fixed sequence of steps through which work, information and actions move through a process. Only once you have a clear understanding of your workflows can you truly assess where software, automation or AI adds value.
