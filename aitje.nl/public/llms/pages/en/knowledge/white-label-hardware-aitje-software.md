# White-label hardware, AITJE software

Official page: https://aitje.com/en/knowledge/white-label-hardware-aitje-software

> White-label hardware with ‘AITJE’ software means that ‘AITJE’ selects suitable hardware and provides the software layer, configuration and AI functionality tailored to the application.

### What does ‘white-label hardware’ mean?

White-label hardware refers to existing or selected hardware that is not designed from scratch as the company’s own hardware product, but is chosen because its specifications are suited to the application. AITJE uses this as a basis to deliver a practical local AI solution.

### What is the value of ‘AITJE’?

The value lies not only in the device itself, but above all in the combination of hardware selection, software, configuration, AI functionality, access and management. ‘AITJE’ ensures that the solution is fit for purpose for the organisation and the process for which it is intended.

### Why not always build your own hardware?

Developing hardware from scratch is often slow, expensive and unnecessary. For many AI applications, it is wiser to choose proven hardware and carefully design the software layer, configuration and AI workflow to suit it.

### How does this fit in with local AI?

Local AI requires hardware that is sufficiently powerful, stable and suitable for the task. By selecting the hardware based on its intended use, a solution can run locally without each application becoming entirely dependent on external platforms.

### What do you ultimately get?

The result is not just a box of specifications, but a working AI solution on selected hardware, supported by AITJE software. Think of an assistant, agent, workflow, integration or local AI application.
