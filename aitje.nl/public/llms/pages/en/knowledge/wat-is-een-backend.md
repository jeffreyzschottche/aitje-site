# What is a backend?

Official page: https://aitje.com/en/knowledge/wat-is-een-backend

> The backend is the part of the software where processing, logic, integrations and data flows run behind the scenes, out of the user’s view. It is the technical layer that ensures an app or website can actually do something.

### What do developers mean by this?

The backend is the layer behind a website, dashboard or app. This is where requests are processed, data is retrieved, business logic is executed and permissions are checked. The user does not usually see this layer directly, but it does determine how the system behaves.

### What is typically running in the backend?

Consider APIs, databases, authentication, logging, integrations with other systems, document processing and server logic. In AI applications, the backend can also handle prompt logic, context selection, RAG queries and the processing of model calls.

### Why is the backend important?

A good interface alone is not enough. If the backend is slow, insecure or poorly designed, the whole application will crash. The backend largely determines reliability, scalability and what is technically possible within a process.

### Which questions are relevant?

When considering quotations or choosing software, it is wise to ask where data is stored, how integrations work, how errors are handled and how logging or access rights are managed. These are typical backend questions that reveal a great deal about the maturity of a solution.

### How does the backend relate to the frontend?

The front-end is what users see. The back-end is what powers it. Together, they form the overall experience. A robust solution therefore not only has a polished interface, but also a back-end that is logical, secure and maintainable.
