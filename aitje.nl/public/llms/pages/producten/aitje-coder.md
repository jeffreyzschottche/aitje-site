AITJE Coder is een eigen alternatief voor diensten zoals Codex en Claude Code: een complete lokale codeeromgeving die projecten leest en wijzigt, commando's uitvoert en programmeertaken iteratief afrondt.

AITJE heeft het uitzoekwerk al gedaan. Geselecteerde lokale codeermodellen, een agent met review en pull requests, een web-app voor beheer en de koppeling met tools als Claude Code, OpenCode, Codex en Aider zitten gebruiksklaar in één product.

## Agent & review

Van nieuwe taak tot beoordeeld resultaat

### Taken en meerdere repositories

Kies repository, startbranch, model en webzoeken. Werk waar nodig over gekoppelde repositories, in een eigen afgeschermde werkmap.

### Live verloop en stoppen

Volg bestanden, commando’s, tests en fouten. Stop een taak met bevestiging; een vastgelopen herhaling krijgt een begrensde herstart.

### Review per bestand

Bekijk wijzigingen naast of onder elkaar. Geef per bestand een oordeel en opmerking. Vergelijk runs of laat een aanpassing opnieuw uitvoeren.

### Goedkeuring en Git

Een reviewer opent de pull request naar GitHub, GitLab of Gitea. GitHub-login met een code en een fork bij ontbrekend schrijfrecht worden ondersteund.

### Wachtrij, planning en rondes

Orden of pauzeer de rij. Plan eenmalig, dagelijks, wekelijks of via cron. Start bij een push of GitHub-/Linear-issue en laat meerdere rondes doorwerken.

### Voorrang voor interactief werk

Werk je zelf in een editor of chat, dan krijgt dat voorrang op de batchtaken. De wachtrij maakt zichtbaar wat wacht, draait of op review staat.

De omgeving voor je bestaande ontwikkelwerk

### Chat en hulpassistent

### Desktop, mobiel en taal

Dezelfde web-app op een groot of klein scherm, licht of donker. Nederlands, Engels, Duits en Frans; telefoon en laptop zijn de toegang tot de box.

## Veelgestelde vragen

### Wat is AITJE Coder?

Een eigen omgeving voor coding agents: een lokaal alternatief voor diensten als Claude Code en Codex. Agents lezen en wijzigen je code, voeren commando's uit en werken taken iteratief af.

### Werkt Coder met mijn eigen tools?

Ja. Claude Code, OpenCode, Codex, Aider, Cline, Continue en andere tools verbinden met jullie eigen modelomgeving. De pagina /connect in de AITJE-omgeving geeft het certificaat, je persoonlijke sleutel en een kant-en-klare configuratie per tool. Taken voor de agent geef je in de web-app.

### Zijn lokale modellen goed genoeg voor echt werk?

Voor veel taken wel, zeker als je ze klein en duidelijk maakt. Bekijk hoe een marketingbureau met AITJE Coder [25 nieuwe gamelevels per week maakt](https://aitje.com/cases/coder-game-in-24-uur), of vraag een demo aan om de mogelijkheden voor je eigen werk te bespreken.

### Kan ik zelf een ander model toevoegen?

Ja. Een lokaal model toevoegen of verwijderen gebeurt in jullie modelomgeving; AITJE kan dat los of via een SLA voor je doen. Een beheerder kan daarnaast een externe aanbieder toevoegen. Die modellen staan standaard voor niemand open: je staat ze per gebruiker toe.

### Met welke programmeertalen en frameworks kan AITJE Coder werken?

Je kunt met alle programmeertalen en frameworks werken; Coder is niet beperkt tot één vaste stack. Via skills kun je aanvullende documentatie, instructies en projectafspraken meegeven. De kwaliteit hangt af van het gekozen model en de beschikbare context, dus bij een specifieke stack testen we op jouw taken.

### Kan AITJE Coder aan een bestaande codebase werken?

Ja. Coder kan bestaande projecten lezen, uitleggen en aanpassen. Je hoeft dus geen nieuw project te beginnen. Met projectdocumentatie en duidelijke instructies geef je de agent context over de structuur en de afspraken in je codebase.

### Hoe bepaal ik welke bestanden en commando’s een coding agent mag gebruiken?

Bij taken via de web-app werkt de agent in een afgeschermde container met een eigen kopie van de repository. Hij mag pakketten installeren, maar kan jullie interne netwerk niet bereiken. Je bepaalt per repository de toegang; voor GitHub log je eenmalig in met een code, zonder zelf een token te maken. Werk je met een eigen tool zoals Claude Code of OpenCode, dan bepaalt die tool welke bestanden en commando's de agent mag gebruiken.

### Kan ik wijzigingen van AITJE Coder eerst beoordelen voordat ze worden toegepast?

Ja. Bij taken via de web-app verandert er niets tot je het resultaat goedkeurt. Je leest het verslag van de agent en ziet elke gewijzigde regel. Goedkeuren opent een pull request bij GitHub, GitLab of Gitea; Wijzigingen nodig keurt af of laat de agent opnieuw beginnen. Bij interactief gebruik bepaalt je eigen tool welke goedkeuringsmomenten er zijn.

### Kan AITJE Coder ook tests schrijven en fouten opsporen?

Ja. Coder kan tests schrijven, bestaande tests uitvoeren en fouten onderzoeken. De agent kan daarvoor je code, foutmeldingen en testresultaten gebruiken om een wijziging voor te stellen. Je kunt de tests en wijzigingen vervolgens zelf beoordelen.

### Moet AITJE Coder op een box op kantoor draaien?

Nee. De omgeving kan op een BOSGAME M5/M6, een geschikte Mac mini, bestaande hardware, een lokale server, een cloudserver bij bijvoorbeeld Hetzner of DigitalOcean of een AITJE-server draaien. Applicatie, agents en modelverwerking kunnen samen of afzonderlijk worden ingericht. AITJE zoekt de omgeving die past bij jullie workflow en gewenste onafhankelijkheid.

### Kan de coding agent taken inplannen en pull requests voorbereiden?

Ja. Je kunt taken eenmalig of herhaald plannen, met ondersteunde tijdschema’s en push- of issuegebeurtenissen. De server zet werk in de wachtrij. De agent werkt in een eigen werkkopie, toont wijzigingen en controles en bereidt na review een pull request voor. De benodigde server, rechten, modellen en Git-diensten moeten beschikbaar zijn.
