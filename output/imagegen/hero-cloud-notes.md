# Hero sky collage

Built-in image_gen tool used for the transparent photographic cloud asset.

Asset: `aitje.nl/public/img/redesign/hero-cloud-bank.webp`

## Final prompt

Use case: photorealistic-natural. Asset type: transparent cloud cutout for a premium nature-collage website hero. One wide sculptural bank of white cumulus clouds, a larger billowing cluster on the right and a lower trailing cluster toward the left. Real meteorological cloud photography, beautifully dimensional cotton-like shapes, sunlit cream-white tops and very subtle cool pale blue shadows beneath, gentle morning sunlight from upper right. Strong recognizable naturally irregular silhouette with fine vapor only at the very outer edges; the cloud body must remain opaque. Landscape 1536x1024 framing, cloud occupies central 85% width and middle 60% height, generous fully transparent space on ALL four sides so no clouds are cropped. Genuinely transparent alpha background, no sky, no horizon, no ground, no objects, no birds, no text, no frame, no cast shadow, no flat illustration, no cartoon. The purpose is a clean photographic paper-cut collage layer on pale blue sky, not a fog overlay. Detailed natural billows, calm and airy.

## Composition

Pale blue CSS sky, two photographic cloud layers behind the existing egg/rock cutout, and the existing swallow cutout. Responsive placement preserves reading space; decorative images are hidden from assistive technology. The existing reduced-motion treatment for the egg remains unchanged.
